# LED bar firmware

The tsx-ledbar-fw repo holds open firmware for the Crestron USB LED bar. It also holds the tools that load the firmware. The firmware is tested on the TSW-1060-LB LED bar. Other LED bar models are not tested. The stock firmware stays the default. This firmware is optional.

- [Install and tools](../README.md): install the firmware, load an image by hand, go back to the stock firmware, and the console and effect commands.
- [LED control](leds.md): LED names, the board variant and the LED maps, base color, patterns, effects, power limits, dimming and LED commands.
- [Update protocol](update-protocol.md): framing, modes, packets and the update sequence of the bootloader.
